# apexVIP · krav

En generell forsknings- och träningsplattform. Pseudonyma deltagare, Polar H10 först, syntetiska data för utveckling. Ingen migration av tidigare databas.

Första leverans: verkligt autentiserat ingest-API, beständig lagring, idempotenta paket, sessionslista och detaljer, flexibel analys med numerisk tid, overlay, synkroniserad markör/zoom, luckor/händelser och sparade versionshanterade upplägg. Rådataexport och konfigurerbara formulärversioner.

Nästa kedja: mobil HR/RR → lokal SQLite → beständig utkorg → samma API. Sensorintegration återanvänds från ursprungligt repo. ECG och H10-rörelse får egna nästa milstolpar. Bakgrundsinsamlingsförmåga kräver fysisk verifiering.

Ingen fullständig liveplattform, medicinska slutsatser eller automatisk stressklassificering. Produktionsdrift, kontoprovisionering, retention och driftsäkerhetsgranskning är separata leveranssteg.

# Verifierbara milstolpar

1. **Genomförd:** isolerat repo, källinventering och gemensamt versionerat kontrakt.
2. **Genomförd:** API → SQLite → session och analys i webbläsaren.
3. **Genomförd:** synkroniserade paneler, overlay/enheter, event/lucka, sparat och återöppnat upplägg samt arbetsyteisolering.
4. **Delvis genomförd:** mobilens beständiga lagring och paketutkorg verifierade genom syntetiskt simulatorpass, omstart och API-kvittens. Fysisk iOS/H10-verifiering är nästa kontroll.
5. **Planerad:** ECG/H10-acceleration, explicit koordinatmodell, utökat formulärflöde och stora datavolymer.
6. **Planerad:** hårdvaruavbrott, tillgänglighetsgranskning, SDK/säkerhetsuppdatering, produktionsautentisering och drift.

[Körd verifiering](STATUS.md) och [fysisk testplan](MOBILE_VERIFICATION.md) hålls separata. Mobiltypkontroll, native bygge och simulatorprov är inte hårdvarutester.
